# SCAA for assembly sealing interface morphology inversion

PyTorch training and inference code accompanying *Morphology Inversion for Assembly Sealing Interfaces Using Decoder-Guided Cross-Axis Attention*.

The release contains the code and recorded configurations, the 891 prepared flange morphology cases, and archived predictions and metrics for 18 configurations across seeds 2085, 4125, and 8012. All runs share the original 712/89/90 case split.

See [Releases](https://github.com/xquan-xj/SCAA/releases) for downloads and checksums. Training and evaluation instructions are in the source archive.
